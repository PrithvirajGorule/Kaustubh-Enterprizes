Kaustubh Enterprises Industrial Showcase

Welcome to the Kaustubh Enterprises Industrial Showcase project! This web application is designed to enhance the visibility of Kaustubh Enterprises' products and facilitate customer interactions.

Project Overview

The Kaustubh Enterprises Industrial Showcase project leverages React.js for the front end and Firebase for backend services. It provides a platform for showcasing industrial products, generating quotations, and communicating with potential clients.

Features

Product Showcase: Display a comprehensive catalog of industrial products.
Quotation Generation: Easily request and generate quotations for selected products.
Client Communication: Streamline communication with potential clients.
Responsive Design: Optimized for both desktop and mobile devices.
