Kaustubh Enterprises Industrial Showcase

Welcome to the Kaustubh Enterprises Industrial Showcase project! This web application is designed to showcase products, generate quotations, and facilitate communication with potential clients. It aims to enhance the visibility of Kaustubh Enterprises' offerings and streamline customer interactions.

Project Overview

The Kaustubh Enterprises Industrial Showcase project uses React.js for the front end and Firebase for backend services. The platform enables users to view products, request quotations, and communicate with the company seamlessly.

Features

Product Showcase: Display a catalog of industrial products.
Quotation Generation: Request and generate quotations for selected products.
Client Communication: Facilitate easy communication with potential clients.
Responsive Design: Optimized for both desktop and mobile devices.
